Artifact Viewer Handbook

How to open the artifact viewer, keep it on your computer like any other app, and put your own scanned objects into it. No software to buy, nothing to set up.

Open it

The viewer is a web page. You do not download or install anything to use it — you visit an address, the same way you would visit any website. Here it is:

The address
nikkinaq-a11y.github.io/artifact-viewer

Works on any reasonably modern Mac or Windows computer, in Chrome, Edge, Safari or Firefox. Nothing is uploaded and no account is needed.

You will see an empty pedestal in a dark room. That is correct. The viewer arrives empty on purpose, because the museum's scans are not published on the open internet. You add objects yourself, or open a collection someone sends you — both are covered below.

Where the address comes from. The viewer is stored on GitHub, a website developers use to keep their work. The GitHub page at github.com/nikkinaq-a11y/artifact-viewer holds the instructions a computer follows to build the viewer; the address above is the finished, usable version. If someone sends you the GitHub page and you only see folders and files, you are in the workshop rather than the gallery — use the address above instead.

Two ways to use it

Both run exactly the same viewer. The difference is whether it lives in a browser tab or behaves like an installed program.

Nothing to install

In a browser tab

Visit the address and use it. Best for showing someone quickly, or on a computer that is not yours.

Needs an internet connection the first time.

Recommended if it is your computer

Installed as an app

Sits in your Dock or Start menu with its own icon, opens in its own window with no address bar, and works with no internet at all.

Takes about ten seconds to set up, once.

Install it as an app

This does not download an installer or ask for a password. The browser keeps a copy of the viewer on your computer and gives it an icon.

On Mac or Windows, using Chrome or Edge

  1. Open the address in Chrome or Edge.

  2. Look at the right-hand end of the address bar for a small install icon — a screen with a downward arrow.

    If you cannot see it: open the browser's three-dot menu and look for Cast, save and share → Install page as app, or simply Install.

  3. Click it, then click Install.

  4. The viewer opens in its own window and now appears in your Applications folder or Start menu. Open it from there in future.

On a Mac, using Safari

  1. Open the address in Safari.

  2. From the menu bar choose File → Add to Dock.

  3. Confirm the name. It now sits in your Dock like any other app.

It genuinely works offline. Once installed, the viewer opens on a plane, in a storage room, or in a gallery with no guest wi-fi. Your objects are kept on your own computer, not on a server.
There is no separate download file yet. You may have expected a .dmg or .exe to download from GitHub. A double-clickable Mac application can be built from this project, but one has not been posted for download, so the browser install above is currently the way to get the viewer onto a computer. It gives you the same thing: an icon, its own window, and offline use.

Put an object on the pedestal

Drag a 3D file from your desktop onto the viewer window and let go. That is the whole procedure. The object is measured, sized to the pedestal and lit automatically. It stays in your collection until you remove it, including after you close and reopen the viewer.

If you would rather pick from a list, click the Gallery tab in the top-right corner, then + Add artifact.

File types it accepts

TypeWhat to expect
.glb .gltf The most reliable. Everything the object needs is inside one file.
.fbx Usually fine. Some carry their colour image separately — see the grey-object note below.
.obj Drag the .obj, its .mtl and its image files in together, all selected at once.
.ply Common from scanners. Colour is usually built into the surface.
.stl Shape only. This format cannot store colour, so it always looks plain.
.usdz .usd Supported, but less thoroughly tested than the rest.
If an object arrives grey or black. Nothing is broken. Some files record only the location of their colour image on the computer that made them — a path your computer cannot follow. Select the 3D file and its .jpg together and drag them in as one selection. The colour appears, and it is remembered from then on.

Send someone a collection

Your objects live on your computer only. To let a colleague see the same set, you send them a collection file.

  1. Open the Gallery tab and click Export gallery. You get a single .zip file.

    It contains every object, its colour images, and the way you had the scene arranged — pedestal size, lighting, background, camera.

  2. Send them that file, along with the address at the top of this page.

    Five masks come to roughly 25 MB, which emails comfortably. Very large scans will need a shared drive instead.

  3. They open the viewer, click Gallery → Import gallery, and choose the file. They see exactly what you staged.

Importing replaces what is already there. A collection arrives as the curated set it was meant to be, rather than mixing into someone's existing objects. Export your own collection first if you want to keep it.

Moving around

Click and drag to walk around the object. Scroll to move closer or further away. Everything else is a single key — press it, and press it again with Shift held to go the other way.

KeyWhat it does
CNext camera angle — seven fixed views, all from the front (turn the object with R to see its other sides)
DCamera distance — the same view taken from further back, then back again
ONext object in your collection
RTurn the object 30° on its base
PMake the object larger
HPedestal taller
KPedestal wider
LPedestal deeper
BScene — dark room, then white, then horizon, then silhouette
VHide the pedestal, leaving the object floating
FFront light on or off — good for reading surface detail. No effect in silhouette, where the whole rig is off
TabShow this list on screen. The readout in the corner collapses too — click the camera chip at the lower left

The four scenes suit different jobs: dark is the gallery look, white is for documentation photographs, and horizon puts a pale blue floor against grey walls so you can see exactly where the object is standing.

Silhouette is not simply a fourth background. The back wall becomes a lit white panel and every lamp in the room goes out, so nothing falls on the object at all and it reads as a flat black cut-out against the glow — an outline for comparing profiles, not a surface for reading detail. Because the rig is off, F does nothing here, and the on-screen readout says so.

D is a second framing rather than more angles. It holds whichever view you are on and moves the camera back, keeping the lens the same, so the pair reads as one shot from further away instead of a wider one.

When something looks wrong

The pedestal is empty and nothing happens
The viewer starts empty by design. Drag a 3D file onto the window, or import a collection file from a colleague.
My objects have vanished
Objects are stored by the browser, so clearing your browsing data or history removes them, and they do not follow you to another computer or another browser. Keep your original files, and export a collection file for anything you would hate to rebuild.
A large scan is slow, or the tab freezes
Very large scans — over roughly 100 MB — are demanding. Close other tabs and try again. If a particular file always fails, it likely needs to be reduced in size before it can be used comfortably.
The object is on its side or far too small
The viewer sizes and seats each object automatically, but it cannot know which way up a scan was saved. Use R to turn it and P to resize.
I opened the GitHub page and it is full of files
That is the workshop, not the gallery. Use the address at the top of this page.
